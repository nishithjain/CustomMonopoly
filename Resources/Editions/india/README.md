India Property and Event **card fronts** are published under `Resources/Editions/india/`.

* Property fronts: `PropertyCards/NN_Property_Front.png`
* Event fronts: `EventCards/<Name>_Front.png`

Event **centre artwork** remains in `monopoly-edition-generator/assets/cards/editions/india/event-artwork/`.

QR Card Backs are generated by the separate QRCode workspace into each card's `qrAsset` path.

See `ASSET_LIFECYCLE.md` at the repository root for the full workflow.
