# Undo Workflow

Single-depth undo via `UndoLastAction`. Eligibility from `UndoSupport.canUndo(session)`.

## Undoable (when engine allows)

Rent, purchase, GO (bank credit), jail payment, location fee.

## Not undoable

Events, actions during debt resolution.

## UI

**BANK ACTIONS → UNDO LAST ACTION** shows confirmation with last transaction description.
