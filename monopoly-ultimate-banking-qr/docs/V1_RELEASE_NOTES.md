# V1 Release Notes

**Version:** 1.0.0 (versionCode 1)  
**Display name:** Banking QR  
**Build type:** Debug APK for validation; Release APK unsigned unless signing key configured

## What this release is

A personal-use Android banking companion for **Monopoly Ultimate Banking** with physical QR cards, board, dice, and tokens.

## Included functionality

- New Game and player setup (2–4 players, M1500 each)
- Property scan → buy, rent, owner landing, rent levels 1–5
- All 23 Event cards with guided workflows
- Advanced Banking: GO, Location, Jail, Auction, Debt, Bankruptcy, Winner, Undo
- Autosave and Resume
- Recent transaction history
- Offline operation (no network required for gameplay)

## Requirements

- Android 8.0+ (API 26+)
- Camera permission for QR scanning
- Printed Ultimate Banking QR card set (49 cards)
- Physical game board and components

## Installation

1. Install `app-debug.apk` (development validation) or signed release APK when available.
2. Grant camera permission when prompted.
3. Launch **Banking QR** → **NEW GAME**.
