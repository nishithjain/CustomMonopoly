# Banking Values

Fixed monetary amounts for the current Ultimate Banking edition live in master data, not in Game Engine or UI literals.

## Source of truth

```text
data/banking_values.json
```

The Android runtime copy is generated by `tools/sync_android_assets.py`:

```text
android-app/app/src/main/assets/game/banking_values.json
```

Do not edit the Android asset directly.

## Loading

```text
AndroidGameDataLoader
    ↓
JSON strings
    ↓
GameDefinitionLoader (:game-core)
    ↓
GameDefinitions.bankingValues
```

Missing or invalid banking values fail `GameDefinitions` validation. The engine does not fall back to hard-coded amounts.

## Fields

| Field | Meaning | Current Ultimate Banking edition |
| ----- | ------- | -------------------------------- |
| `currency.code` | Currency identifier | `M` |
| `currency.symbol` | Display prefix | `M` |
| `currency.scale` | Minor-unit scale (reserved for future editions) | `1` |
| `startingBalance` | Amount every registered Player receives at game start | M1500 |
| `goSalary` | Amount collected when passing/landing on GO during normal movement | M200 |
| `locationFee` | Amount paid to use Location | M100 |
| `jailReleaseFee` | Amount paid to leave Jail (manual payment and the same fee after three failed doubles) | M100 |
| `auctionBidIncrement` | Amount each Auction bid increases (also the first bid) | M20 |
| `eventAmounts.M50` | Reusable standard Event M50 amount (Highway Tax per owned Property) | M50 |
| `eventAmounts.M200` | Reusable standard Event M200 amount (both-player credits) | M200 |

JSON keys `eventAmounts.M50` and `eventAmounts.M200` are semantic amount identifiers. They stay stable even if a future edition stores different numeric values.

## Current Ultimate Banking edition

```text
Starting Balance = M1500
GO = M200
Location = M100
Jail Release = M100
Auction Increment = M20
Event Standard 50 = M50
Event Standard 200 = M200
```

> Fixed monetary rules must be read from `BankingValues` and should not be hard-coded in UI or Game Engine commands.

## What does not belong here

Property `purchasePrice` and `rentLevels` stay in `properties.json` (or an edition-specific properties file).

Event behaviour stays in the Event Engine and `event_engine_rules.json`. Those rules resolve `bankingValues.eventAmounts.M50` / `M200` instead of embedding edition-specific cash amounts in Kotlin.

## Display

`MoneyFormatter` in `:game-core` formats amounts with `bankingValues.currency.symbol`. The current edition displays `M1500`, `M200`, `M100`, `M20`, and `M50`.

Do not switch the current runtime to `₹` here. A future India file such as `banking_values_india.json` can supply different currency metadata and amounts when edition switching is implemented.

## Validation

```text
python tools/validate_banking_values.py
```

Writes `data/banking_values_validation.txt`.
