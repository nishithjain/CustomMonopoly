# Data Directory

Authoritative master data now lives in:

```text
data/common/                 shared identity and rules
data/editions/<editionId>/   edition Property/Event/board/economy data
```

See [EDITION_ARCHITECTURE.md](../docs/EDITION_ARCHITECTURE.md).

Generated Android copies under `android-app/app/src/main/assets/game/` must not be edited by hand.
